## Projects

## How I'm Learning

I use a mix of different resources while learning Python:

- FreeCodeCamp for the basics
- YouTube videos and tutorials
- Official documentation
- Google when I get stuck or want to understand something better
- AI tools such as ChatGPT and Claude for explanations and debugging help
- Small projects so I can actually practice instead of only watching tutorials

I try to use AI more like a tutor than a shortcut, so I still have to think through the problem, write the code myself, and understand what it does.

I'm also using Tkinter to learn how desktop GUI applications work.

My goal is not just to make the code work. I want to understand what I wrote, why it works, and be able to explain it myself.
